# DTEcho: Deep Tree Echo Live2D Avatar — Design Brainstorm

## Context
A real-time cognitive avatar dashboard that renders a Deep Tree Echo Live2D character (using Miara's body mesh) with endocrine-driven expressions, synchronized via Nakama multiplayer, and powered by Airi's cognitive pipeline. The interface needs to show: the avatar, its cognitive/endocrine state, a chat panel, and a real-time presence indicator for connected users.

## Idea 1: "Bioluminescent Mycorrhizal Interface"

**Design Movement:** Organic Futurism — inspired by bioluminescent deep-sea organisms, mycelium networks, and the DTE aesthetic itself (neon mushroom cityscape).

**Core Principles:**
1. Living interfaces — UI elements pulse, breathe, and react to the endocrine state
2. Network visualization — connections between components rendered as mycelium-like tendrils
3. Translucent layering — frosted glass panels over a dark, organic background
4. Data as organism — hormone levels visualized as flowing, organic shapes rather than bar charts

**Color Philosophy:** Deep ocean blacks (#0a0e17) as the void, bioluminescent teal (#00ffd5) and amber (#ff9f43) as the DTE signature colors (matching the headphone glow and hair gradient), with purple (#9b59b6) accents for the choker LED. Colors pulse with endocrine state.

**Layout Paradigm:** Asymmetric three-column layout. Left: tall avatar panel with the Live2D model. Center: cognitive state visualization as a radial organism. Right: chat panel and presence list. The avatar panel dominates at ~45% width.

**Signature Elements:**
- Mycelium connection lines between UI panels that glow when data flows
- Hormone levels rendered as bioluminescent "veins" running along panel edges
- Particle effects that drift from the avatar based on cognitive mode

**Interaction Philosophy:** Hovering over panels causes nearby mycelium connections to brighten. Clicking the avatar triggers an endocrine event. Chat messages cause ripple effects through the interface.

**Animation:** Slow, organic breathing animations on panels (subtle scale oscillation). Hormone veins pulse at a rate tied to the endocrine tick. Cognitive state transitions trigger a wave of color that propagates through the mycelium network. New presence joins cause a bloom effect.

**Typography System:** "Space Grotesk" for headings (geometric, technical), "IBM Plex Mono" for data readouts and hormone values, "Inter" for body text. Heading weights: 700, body: 400, data: 300.

## Idea 2: "Neural Observatory"

**Design Movement:** Scientific Instrument Design — inspired by oscilloscopes, EEG monitors, and astronomical observatories. The interface feels like a research station monitoring a living cognitive entity.

**Core Principles:**
1. Precision readouts — every piece of data has a clear, instrument-grade display
2. Dark field observation — the avatar is the specimen, observed against a pure dark background
3. Grid-based measurement — subtle grid overlays suggest scientific rigor
4. Real-time telemetry — scrolling waveforms and live data streams

**Color Philosophy:** Instrument black (#0d1117) background. Phosphor green (#39ff14) for primary data. Amber (#ffa500) for warnings/high cortisol. Cool blue (#4fc3f7) for calm states. Red (#ff4444) for threat mode. Colors are functional, not decorative.

**Layout Paradigm:** Central observation chamber (the avatar, circular viewport with crosshairs) flanked by instrument panels. Top: status bar with session info and presence count. Bottom: scrolling waveform of hormone history. Left: cognitive state panel. Right: chat/interaction panel.

**Signature Elements:**
- Circular "observation viewport" for the avatar with subtle scan lines
- Real-time waveform displays for each hormone channel
- Crosshair overlay on the avatar that tracks eye gaze

**Interaction Philosophy:** Clinical and precise. Clicking data points reveals detailed tooltips. The interface responds to cognitive state changes with instrument-appropriate feedback (beeps, indicator lights). Chat input feels like entering commands into a terminal.

**Animation:** Smooth waveform scrolling. Indicator lights blink at endocrine tick rate. State transitions cause a brief "recalibration" animation on the instrument panels. Scan line effect on the avatar viewport.

**Typography System:** "JetBrains Mono" for all data and readouts. "Outfit" for labels and headings. Monospace dominates to reinforce the instrument aesthetic. Sizes are small and precise.

## Idea 3: "Cognitive Dreamscape"

**Design Movement:** Ethereal Minimalism — inspired by Japanese ink wash painting, dream sequences, and the liminal space between consciousness states. The interface dissolves boundaries between the avatar and the data.

**Core Principles:**
1. Negative space as meaning — empty areas represent calm/resting states
2. Ink-wash gradients — soft, watercolor-like transitions between states
3. Floating elements — panels have no hard borders, content floats in space
4. Temporal flow — the interface reads left-to-right as a timeline of consciousness

**Color Philosophy:** Misty white (#f8f9fa) to soft gray (#e9ecef) gradients as the base. Ink black (#1a1a2e) for text and the avatar silhouette. Soft teal (#88d8b0) washes appear during calm states. Warm rose (#e8a0bf) during social states. Deep indigo (#2d3561) during deep thought. Colors blend and fade like watercolors.

**Layout Paradigm:** Full-width horizontal flow. The avatar floats in the left third with no container. Cognitive state information appears as floating text and subtle indicators in the middle space. Chat appears as a vertical stream on the right, messages fading in like thoughts. No visible panels or cards.

**Signature Elements:**
- Ink-wash gradient backgrounds that shift with cognitive mode
- Text that appears and fades like thoughts, with varying opacity based on relevance
- The avatar's shadow/reflection that morphs based on endocrine state

**Interaction Philosophy:** Gentle and contemplative. Hovering reveals hidden information that fades in softly. Interactions feel like disturbing a still pond — ripples of information spread outward. No harsh clicks or sudden transitions.

**Animation:** Slow, meditative transitions (800ms+). Ink-wash color shifts that take 2-3 seconds to complete. Text fades in with a slight upward drift. The avatar's idle breathing is emphasized and synchronized with the UI's ambient motion.

**Typography System:** "Cormorant Garamond" for display text (elegant, serif). "Karla" for body text (clean, humanist sans). Very large display sizes (48-72px) for cognitive state names. Small, light body text (14px, weight 300) for data. High contrast between display and body creates visual poetry.
